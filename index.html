    Upwork connection

    The server checks Upwork on your behalf, so it needs your Upwork session. In a browser where you are logged in to Upwork, open a job search, open the developer tools (F12) → Network, click any request to www.upwork.com and copy its request headers below. Saved values are never shown again; leave a field empty to keep what is saved.

    Upwork blocks requests made by this server itself. Install the Upwork Tracker Connector extension (the extension folder) in that browser and turn on Check Upwork through this browser in its popup: the checks are then made from the browser while it is open, and the session saved here stays up to date.

    The full value of the request's cookie header. The API token and organization are read from it.
    From a request to /api/graphql/v1?alias=userJobSearch. Tried before the cookie tokens.
    Upwork's security check ties cf_clearance to the browser it was issued to, so use the user agent of the browser you copied the cookies from.
